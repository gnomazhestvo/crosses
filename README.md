Задача:
Выбрать внутри пары/сообщества единую модель кроссовок, которые больше всего нравятся всем участникам.

Решение:
1. наполнить БД набором моделей, которые нравятся каждому из партнеров по отдельности;
2. ежедневно проходить мини-игру, которая по результатам будет присваивать каждой модели кроссовок рейтинг;
3. создать таблицу моделей-лидеров.

Идеи:
- мини-игра в виде single-elimination выбора кроссовок;
- напоминание в тг;
- ...
